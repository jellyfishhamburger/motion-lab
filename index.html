03

滚动：动效真正的高发区

IntersectionObserver 只做一件事——决定「什么时候开始」。触发一次就解绑，比监听 scroll 便宜得多。

0个动效来源
0个能上生产
0行第三方依赖
0帧率目标 · 只动 transform / opacity
  • 01进场只做一次

    动画结束后 unobserve，回到视口不重播

  • 02只动合成层

    transform / opacity / clip-path，不碰 width、top

  • 03错开 60–90ms

    同组元素依次入场，比一起出现有节奏

  • 04认 prefers-reduced-motion

    系统开了「减少动态效果」就整页关掉

05

三个旋钮：动效强度 / 信息密度 / 圆角

全部写到 :root 的 CSS 变量上，全站动画时长用 calc(… * var(--mo)) 计算。改一个数，整页手感就变了——这也是「设计系统」最实用的一部分。

--mo:1; --dens:1; --radius:18px;
